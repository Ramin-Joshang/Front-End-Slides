HTTP & HTTPS: The Web's Conversation Rules

HTTP Standard

HyperText Transfer Protocol. The foundation of data exchange on the web.

  • Defines rules for how browsers ask for files.
  • Data is sent in "Plain Text" (visible to anyone).
  • No verification of who the server actually is.
HTTPS Secure

The "S" stands for Secure. It's HTTP layered with encryption (TLS/SSL).

  • Encryption: Scrambles data so only you can read it.
  • Identity: Proves the website is who they say they are.
  • Privacy: Essential for passwords and credit cards.
A typical network conversation:
Browser (Request) GET /index.html HTTP/1.1
Server (Response) HTTP/1.1 200 OK
