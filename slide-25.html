کارگاه عملی: ایجاد پوشه اولین پروژه وب

مراحل گام‌به‌گام
1
۱. باز کردن نرم‌افزار
منوی File سپس انتخاب Open Folder…
2
۲. ایجاد پوشه جدید
نام‌گذاری پوشه: my-first-project
3
۳. انتخاب پوشه
پوشه به عنوان فضای کاری فعال شما باز می‌شود
4
۴. بررسی پنل Explorer
نام پوشه را در بالای سایدبار ببینید my-first-project
روش دوم: از طریق خط فرمان و ترمینال
~$ cd Desktop
~$ mkdir my-first-project
~$ cd my-first-project
~$ code .   # opens VS Code here
نتیجه کار در پنل Explorer
MY-FIRST-PROJECT
← index.html lives here next
Pro tip: توصیه حرفه‌ای: تمام پروژه‌های وب را درون یک پوشه مادر مشخص نگه دارید. ~/Projects or Desktop/dev parent folder — easy to find, easy to back up.
