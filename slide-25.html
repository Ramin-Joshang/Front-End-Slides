Lesson 01 // Introduction

Hands-on: Creating Your Project Folder

Follow along — 3 steps
1
Open VS Code
File → Open Folder…
2
Create a new folder
Name it: my-first-project
3
Select that folder
VS Code opens it as your workspace
4
Verify in Explorer panel
You should see my-first-project
Terminal — Alternative: command line
~$ cd Desktop
~$ mkdir my-first-project
~$ cd my-first-project
~$ code .   # opens VS Code here
Result — Explorer Panel
MY-FIRST-PROJECT
← index.html lives here next
Pro tip: Keep all projects inside a single ~/Projects or Desktop/dev parent folder — easy to find, easy to back up.
