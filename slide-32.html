Lesson 01 // Introduction

Homework and Next Steps

01

Install Your Development Tools

Download and install Visual Studio Code and Google Chrome. Ensure they are pinned to your taskbar for quick access.

02

Setup Your Project Workspace

Create a new folder on your computer named frontend-course. Inside it, create a sub-folder called lesson-01.

03

Create Your First HTML File

Open your lesson-01 folder in VS Code. Create a new file named index.html and type <h1>Hello World</h1>.

04

Verify the Execution

Right-click index.html and open with Google Chrome. Confirm the text displays correctly.

Successful completion of these steps is required before our next lesson on Semantic HTML structure.
