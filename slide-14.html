HTML: The Skeleton of the Web

HTML
HyperText
Markup Language
Structure
Defines every element on the page — headings, paragraphs, images, links — using nested tags that form a logical document tree.
Markup Language
Not a programming language — no logic or calculations. HTML describes content using opening and closing tags read top to bottom by the browser.
Foundation Layer
Every website starts here. CSS adds style; JavaScript adds behavior. Without HTML, there is nothing for them to act on.
Example
<h1> Hello, World! </h1>    <p> My first paragraph. </p>    <a href="page.html"> Click here </a>
