سه بازیگر اصلی وب: کلاینت، مرورگر و سرور

کلاینت (Client)

درخواست‌کننده؛ دستگاه فیزیکی شما (لپ‌تاپ، موبایل یا تبلت) که با آن به وب متصل می‌شوید.

دستگاه کاربر نهایی

مرورگر (Browser)

نرم‌افزار متخصصی که کدها را دریافت کرده و به یک صفحه گرافیکی و زیبا تبدیل می‌کند.

تحلیل و ساخت درخت تگ‌های HTML
اعمال استایل و زیبایی‌های CSS
اجرای دستورات و منطق جاوااسکریپت

سرور (Server)

کامپیوتر قدرتمند و همیشه بیداری که فایل‌ها را ذخیره کرده و به درخواست‌ها پاسخ می‌دهد.

ارائه‌دهنده منابع و داده‌ها

Presenter Notes

In web development, we constantly talk about three primary actors. Let's define them clearly to build our mental model. First, the **کلاینت (Client)**. This is the starting point. It's the device in your hand—your laptop, your iPhone, or even a smart TV. In our context, the client is the one "asking" for something. Second, the **مرورگر (Browser)**. This is a specific type of client software, like Google Chrome or Safari. Think of it as the specialized interpreter. Its job is to take the raw files from the internet and do three key things: parse the HTML structure, apply the CSS styles, and execute the JavaScript logic. Finally, the **سرور (Server)**. This is a powerful computer, usually located in a data center, that stays on 24/7. It "serves" the files. When you ask for 'google.com', a server somewhere finds those files and sends them back to your browser. Transition: "Now that we know the three actors, let's see the sequence of events that happens when they actually start talking to each other."
