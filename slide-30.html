خطاهای رایج مبتدیان و راهکار برطرف کردن آن‌ها

غلط املایی در نام تگ‌ها
خطا <titel>My Page</titel>
اصلاح <title>My Page</title>

نام تگ‌ها باید دقیق تایپ شود. به رنگ تگ در VS Code دقت کنید؛ تگ‌های اشتباه رنگ متفاوتی دارند.

فراموش کردن بستن تگ
خطا <h1>Hello World
اصلاح <h1>Hello World</h1>

Every opening tag needs a matching closing tag. VS Code's bracket pair colorizer highlights mismatches.

Incorrect File Path
خطا src="Images/logo.png"
اصلاح src="images/logo.png"

Paths are case-sensitive on servers. Keep all folder and file names lowercase to avoid broken links.

ذخیره نشدن تغییرات فایل
نشانه Changes not showing in browser
اصلاح Ctrl + S / Cmd + S

وجود دایره در کنار نام فایل در تب ادیتور نشانه ذخیره نشدن است. کلید Ctrl + S را بزنید یا Auto Save را فعال کنید.

پسوند اشتباه در فایل
خطا index.html.txt
اصلاح index.html

سیستم‌عامل ممکن است پسوندها را مخفی کند. در تنظیمات پوشه‌ها گزینه نمایش پسوند را فعال کنید.

کش مرورگر و عدم به‌روزرسانی
نشانه Old content still showing
اصلاح Ctrl+Shift+R (hard reload)

رفرش سخت (Ctrl+Shift+R) کش را دور می‌زند. استفاده از Live Server این مشکل را به کلی حل می‌کند.

Pro tip: نکته طلایی: هر جا به بن‌بست رسیدید، کلید F12 را بزنید و تب Console را باز کنید؛ ارورهای قرمز دقیقاً علت را می‌گویند.
