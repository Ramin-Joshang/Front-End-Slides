Troubleshooting Common Issues

Typo in HTML Tag
Problem <titel>My Page</titel>
Fix <title>My Page</title>

HTML tags must be spelled exactly. Check VS Code's syntax highlighting — unknown tags appear unstyled.

Missing Closing Tag
Problem <h1>Hello World
Fix <h1>Hello World</h1>

Every opening tag needs a matching closing tag. VS Code's bracket pair colorizer highlights mismatches.

Incorrect File Path
Problem src="Images/logo.png"
Fix src="images/logo.png"

Paths are case-sensitive on servers. Keep all folder and file names lowercase to avoid broken links.

File Not Saved
Symptom Changes not showing in browser
Fix Ctrl + S / Cmd + S

A dot on the VS Code tab means unsaved changes. Enable Auto Save under File → Auto Save.

Wrong File Extension
Problem index.html.txt
Fix index.html

OS may hide extensions. Check "Show file extensions" in Explorer settings to confirm the real name.

Browser Cache / No Refresh
Symptom Old content still showing
Fix Ctrl+Shift+R (hard reload)

Hard reload bypasses the cache. Live Server refreshes automatically — install it to avoid this issue.

Pro tip: When nothing works, open DevTools (F12) → Console tab. Red errors point directly to the problem.
