Troubleshooting Common Issues

Typo in HTML Tag
Issue <titel>My Page</titel>
Solution <title>My Page</title>

HTML tags must be spelled exactly. Check VS Code's syntax highlighting — unknown tags appear unstyled.

Missing Closing Tag
Issue <h1>Hello World
Solution <h1>Hello World</h1>

s bracket pair colorizer highlights mismatches.

Incorrect File Path
Issue src="Images/logo.png"
Solution src="images/logo.png"

Paths are case-sensitive on servers. Keep all folder and file names lowercase to avoid broken links.

File Changes Not Saved
Symptom Changes not showing in browser
Solution Ctrl + S / Cmd + S

A dot circle next to the filename indicates unsaved changes. Press Ctrl + S or turn on Auto Save.

Wrong File Extension
Issue index.html.txt
Solution index.html

Operating systems may hide extensions. Enable "File name extensions" in your folder view settings.

Browser Cache Not Updating
Symptom Viewing cached old version
Solution Ctrl+Shift+R (hard reload)

A hard reload (Ctrl+Shift+R) bypasses cache. Using Live Server eliminates this issue entirely.

Pro tip: When nothing works, open DevTools (F12) → Console tab. Red errors point directly to the problem.
